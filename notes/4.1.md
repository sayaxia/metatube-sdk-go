- **版本号独立**：本项目自此使用自己的版本线 `4.x`，不再沿用上游的 `v1.4.0-ltx.N` 编号。
  `VERSION` 文件记录三点式版本（本轮 `4.1.0`），`metatube-server -version` 输出 `v4.1-<短提交>`。
- **镜像改名**：镜像仓库从 `metatube-server` 改为 **`metatube-server-ltx`**，与上游镜像彻底区分，
  避免 `docker pull metatube-server` 时误拉到上游版本。
  → `ghcr.io/sayaxia/metatube-server-ltx:v4.1`、`:latest`、`:dev`；离线包的镜像名同样是
  `metatube-server-ltx:v4.1`。**已部署的 compose 必须同步改 `image`**，否则继续拉旧仓库。
- **镜像标签带 v**：每个发布版同时打 `:v<版本>`（本轮为 `:v4.1`，与 git tag 完全一致）与 `:latest`；
  `:dev` 仍只跟随 `main`。旧的 `:ltx` 别名**停止更新**。
- **多平台产物**：Release 同时提供 Linux amd64 / arm64 裸二进制包（解压即可运行，不必装 Docker）、
  Linux amd64 / arm64 的 `docker load` 镜像包，以及 Windows x64 的服务端与桌面面板。
- **发布说明只写本轮**：从本版起，Release 说明只描述这一轮的改动，不再累积历史条目。
